# Marketing by Oli — Landing Page

Landing page estática para presentar los servicios y el universo visual de Manu Olivieri.

## Ver la demo

Abrí `index.html` en un navegador. No requiere instalación ni compilación.

## Publicar con GitHub Pages

1. En el repositorio de GitHub, abrí **Settings → Pages**.
2. En **Build and deployment**, elegí **Deploy from a branch**.
3. Seleccioná la rama **main** y la carpeta **/(root)**, y presioná **Save**.
4. Cuando termine la publicación, la web estará en `https://gavottiguillermo.github.io/landing-marketing-by-oli/`.

El sitio usa rutas relativas, así que no necesita configuración adicional para publicarse bajo el nombre del repositorio.

## Antes de publicar

- Los cuatro cuadros del portfolio son composiciones web inspiradas en las capturas compartidas; enlazan al perfil de Instagram. Se pueden sustituir por piezas originales y enlaces directos a cada publicación.
- La foto editorial de apoyo se generó para esta demo; no representa a Manu ni a un cliente.
- Confirmar con Manu los textos de servicios y los datos de contacto antes de publicarla.
